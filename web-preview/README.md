# HAEON Web Preview

정적 웹사이트로 옮기기 전, 시안 일부를 실제 HTML/CSS로 확인하는 미리보기입니다.

## Run

```powershell
node .\web-preview\preview-server.js
```

Open:

```text
http://localhost:5174/
```

## Scope

현재 구현 범위는 아래 네 블록입니다.

- Hero
- Start options
- Tutor story
- Final CTA

고화질 이미지, 모션 그래픽, 루프 영상은 이후 실제 파일이 들어오면 각 미디어 영역에 연결합니다.
