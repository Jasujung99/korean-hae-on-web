# Font sources

The web preview self-hosts the font files used by the HAEON design system.

- MaruBuri Regular and SemiBold: NAVER Hangeul, https://hangeul.naver.com/font
- Pretendard Variable 1.3.9: https://github.com/orioncactus/pretendard

MaruBuri is distributed under NAVER's open font license. Pretendard is
distributed under the SIL Open Font License 1.1; its full license is included
as `LICENSE-Pretendard.txt`. Keep these files with the font assets when
redistributing the project.
