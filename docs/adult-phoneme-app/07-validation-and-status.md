# 인계 묶음 검증과 현재 상태

확인일: 2026년 11월 16일

## 확인한 결과

- 저장소 main 기준은 `d2938208e586bb500f0e43d39241b06e09ac53db`이며 현재 본사이트는 Astro 정적 앱이다. 원격 트리에서 AGENTS.md는 발견되지 않았다.
- 운영 배포 workflow는 main push 또는 수동 실행에 연결되어 있다. 인계 작업은 별도 브랜치를 사용하며 운영 배포를 실행하지 않는다.
- 마지막 해온 디자인 적용 PC·모바일 시안의 원본을 보관하고 독립 실행 HTML로 내보냈다.
- 두 원본의 JavaScript 구문을 검사했다.
- 독립 실행 HTML에서 답 선택·확인, 비교 도움 왕복과 응답 상태 유지, 다음 문제, 사전·예문 이동, 내 단어 담기, 교사 상세, 과제 필터, 기록 펼치기를 확인했다.
- 브라우저 폭 320px에서 두 시안의 내용 너비와 스크롤 너비가 같았다. 검사 중 앱 JavaScript 오류는 없었다.
- 추가 문서의 상대 링크와 저장소 대상 경로를 대조했다. 파일 끝 공백과 알려진 비밀키 형식을 검사했으며 발견되지 않았다.

시안 검증에는 외부 요청을 차단한 브라우저를 사용했다. 기본 UI는 대체 글꼴로 동작했다. 실제 음원·DB·인증에 연결한 기능 검증은 아니다.

## 구현 전 상태

개인 초대·기기 세션·API·마이그레이션은 상세 계약만 작성되어 있다. 최초 연결, 재발급, 메신저 미리보기와 동시 claim의 기대 동작은 개발·시험해야 한다. Core 60과 초기 후보도 아직 승인된 운영 데이터로 보지 않는다.

현재 실행 환경에는 GEMINI_API_KEY가 없으며, 해당 Google 프로젝트의 실제 호출·할당량·음원 품질은 확인하지 않았다. 비밀값을 파일이나 로그에 넣지 않았다.

루트 앱 소스·의존성·빌드 설정·배포 workflow·public 경로는 이번 묶음에서 수정하지 않는다. 문서·시안 추가 작업이므로 본사이트의 npm build는 이번 작업에서 다시 실행하지 않았다. 구현 모델은 개발 1단계에서 현재 환경의 기준 빌드를 직접 기록해야 한다.

## 변경 범위

저장소 루트 README에 인계 문서의 입구를 추가하고 `docs/adult-phoneme-app/` 아래에만 새 문서와 검토 시안을 둔다. 앱과 운영 환경의 실제 구현 완료 상태는 [개발 지시서](03-implementation-stages.md)의 완료 보고 형식으로 따로 남긴다.
