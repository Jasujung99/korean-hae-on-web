# PC와 모바일 검토 시안

마지막 해온 디자인 적용 시안을 독립 실행용으로 보관한다.

- [PC 시안](desktop.html)
- [모바일 시안](mobile.html)
- 편집용 원본: [PC fragment](source/desktop.fragment.html), [모바일 fragment](source/mobile.fragment.html)

저장소를 내려받아 HTML을 브라우저에서 연다. GitHub 파일 화면은 소스를 보여주므로 거기에서 앱이 실행되지는 않는다. 필요하면 저장소 루트에서 다음 명령으로 시안 폴더만 서비스한다.

```sh
python -m http.server 8765 --directory docs/adult-phoneme-app/prototypes
```

PC: `http://localhost:8765/desktop.html` · 모바일: `http://localhost:8765/mobile.html`

폰트는 Google Fonts 연결 시 로드하며, 연결이 없어도 대체 글꼴로 기본 화면을 볼 수 있다. 전환·선택은 로컬 시안 상태이며 학습 기록을 서버에 보내지 않는다. 실제 음원은 연결되어 있지 않다.

## 확인할 수 있는 흐름

학습자: 듣기 퀴즈 → 응답 확인 → 비교 도움 왕복 → 다음 문제 → 마무리 → 사전·예문 확장.

교사: 역할 전환 → 목록/개인 상세 → 위치·과제별 기록 → 재청취·체류·중단/재개 펼치기.

## 구현할 때의 해석

역할 전환은 리뷰용이며 운영 권한이 아니다. 시안의 정답·수치·단어 문안은 예시다. 개인 초대·기기 기억·재발급 화면은 이번에 추가한 상세 계약으로 구현해야 하며 이 마지막 시안에는 아직 그 전체 흐름이 그려져 있지 않다.

따라서 시안과 문서가 다르면 개인 초대 계약·데이터 계약을 우선한다. 시안에서 localStorage나 호스트 상태 도구로 선택을 보관하는 동작을 실제 기기 인증으로 복사하지 않는다.

이 파일들은 `docs/`에 보관한다. 기존 본사이트의 `public/`이나 배포 경로에 복사하지 않는다.
