# 해온 소리 연습 (`apps/learn`)

성인 학습 앱의 개발 1단계입니다. 듣기 퀴즈, 비교 도움, 마무리, 사전·예문, 교사 목록/상세의 **화면 껍데기**만 있습니다. 초대, 기기 세션, 음원, 점수, 데이터베이스는 없습니다.

본사이트와 배포는 이 패키지를 설치하지 않습니다. 루트에서 `npm ci` 또는 `npm run build`를 실행해도 여기 의존성과 `apps/learn/dist`는 루트 `dist/`에 들어가지 않습니다. 이유는 [ADR 0001](docs/adr/0001-node-hono-vite.md)에 있습니다.

## 실행

Node.js 22 이상. 저장소 루트가 아니라 이 디렉터리에서 실행합니다.

```sh
cd apps/learn
npm ci
npm test
npm run typecheck
npm run dev
```

개발 화면: `http://127.0.0.1:4174/`

개발 서버는 화면과 `/api/*`를 같은 origin에서 제공합니다. 키와 DB 없이 열립니다. 역할 전환은 이 개발 서버에서만 기본으로 보이며, 교사 로그인이 아닙니다.

프로덕션 서버:

```sh
npm run build
npm start
```

`npm start`는 `http://127.0.0.1:4174`에서 빌드된 화면과 API를 함께 제공합니다. 포트를 바꾸려면 `PORT`를 지정합니다. 빌드 결과만 브라우저 미리보기로 보려면 `npm run preview`입니다. `npm start`와 `npm run preview`에서는 역할 전환이 꺼져 있습니다. 레이아웃만 다시 보려면 `LEARN_SCREEN_PREVIEW=1`을 붙입니다. 그래도 교사 권한은 생기지 않습니다.

## 설정

`.env.example`을 참고합니다. 앱이 읽을 값은 다음뿐입니다.

| 변수 | 의미 |
| --- | --- |
| `LEARN_APP_ORIGIN` | 화면에 보여줄 절대 주소. 비우면 설정 없음으로 표시합니다. DNS와 배포는 바뀌지 않습니다. |
| `LEARN_SCREEN_PREVIEW` | `1`이면 역할 전환 껍데기, `0`이면 숨김. |
| `PORT` | `npm start` 포트. 기본 `4174`. |

제안 호스트 이름은 기본값으로 넣지 않습니다. 환경 변수에 적더라도 화면은 그 주소를 운영 중인 도메인으로 표시하지 않습니다.

## 이 단계에 있는 것

- `GET /api/health`: 저장소와 세션이 없다는 상태.
- `GET /api/config`: 주입된 origin과 미리보기 여부. 쿠키를 발급하지 않습니다.
- 학습자 화면 이동: `/`, `/compare`, `/finish`, `/dictionary`.
- 교사 경로 `/teach`, `/teach/detail`: 미리보기가 아니면 인증 전 안내만 보여 줍니다. 미리보기에서는 빈 목록과 빈 상세만 보여 줍니다.

음원 버튼은 비활성입니다. 선택 확인은 이 브라우저 화면에만 남고, 맞았는지 알려 주지 않습니다.
